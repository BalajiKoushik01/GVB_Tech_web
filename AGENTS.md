# Frontend development

Consult [Google Chrome Modern Web Guidance](https://github.com/GoogleChrome/modern-web-guidance-src) for web changes. Retrieve the relevant guides, prefer native accessible controls and progressive enhancement, and check keyboard interaction, smaller screens and browser compatibility.

## Working references

Apply these references where relevant to the task.

- [Cloudflare security audit](https://github.com/cloudflare/security-audit-skill) for defensive source audits. Map trust boundaries, track coverage and substantiate findings from reviewed evidence.
- [Graphify](https://github.com/Graphify-Labs/graphify) for repository mapping when available. Verify graph claims against source files.
- [Stop Slop](https://github.com/hardikpandya/stop-slop) for direct prose, specific claims and fewer formulaic phrases.
- [Goose](https://github.com/aaif-goose/goose) and [OpenClaude](https://github.com/Twigpine/openclaude) as references for agent tooling and provider interoperability. Use when relevant to a runtime integration or when explicitly selected for execution.
