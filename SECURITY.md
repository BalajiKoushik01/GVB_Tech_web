# Security policy

For suspected vulnerabilities in GVB Tech's website, contact **info@gvbtech.in** with the affected URL/path, reproduction steps, potential impact and non-sensitive proof. Use a private channel for exploit details. Do **not** submit live personal data, credentials or destructive test payloads.

This project is maintained as a public-company website; security fixes are evaluated against the supported `main` branch. There is no published bounty program, response-time guarantee or claim of formal security certification.

Please avoid disrupting the live site, scanning unrelated infrastructure or retrieving customer data. For the implementation's current controls and outstanding deployment responsibilities, see [docs/security.md](docs/security.md).
